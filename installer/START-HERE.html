Install Chill TV

For Android TV boxes such as the Xiaomi Mi Box. No coding needed. It takes about 10 minutes.

Chill TV Home

A calm home screen for the family TV: your apps, clock, weather and a voice assistant.
File: ChillTV-Home.apk

Chill TV Showcase

A home screen for a shop, clinic or office TV: your photos, ads and music.
File: ChillTV-Showcase.apk

Install with a USB stick

  1. Copy the kit to a USB stick. Unzip the download, then copy the whole ChillTV-USB-Kit folder onto any USB stick.
  2. Get a file manager on the TV. On the TV, open Google Play, search for File Commander (free) and install it. Any file manager that can open USB drives works.
  3. Plug in the USB stick into the TV box, then open File Commander. Choose the USB drive, open ChillTV-USB-Kit, and pick ChillTV-Home.apk or ChillTV-Showcase.apk.
  4. Allow the install once. The TV says it can't install apps from this source. Choose Settings, turn on Allow from this source for File Commander, then go back and choose Install.
    On some boxes this switch is in Settings › Device Preferences › Security & restrictions › Unknown sources.
  5. Make it your home screen. Open Settings › Apps › Default apps › Home app and choose Chill TV. Then press the Home button on the remote.
    Many TV boxes don't have a Home app choice. Then Chill TV still works from Apps, and the PC helper below makes it the home screen in two minutes.

Make it the home screen with a Windows PC

  1. Turn on USB debugging on the TV. Settings › Device Preferences › About, press OK on Build 7 times. Then Settings › Device Preferences › Developer options › turn on USB debugging. The TV and the PC must be on the same Wi-Fi.
  2. Run the helper. In the kit, open PC helper (Windows) and double-click Start Chill TV Helper.cmd. Type the TV's address (in Chill TV Settings › Remote, or the TV's Wi-Fi settings).
  3. Allow the PC when the TV asks "Allow USB debugging?" (tick Always allow). Then choose 1 for Home or 2 for Showcase.
If the Home button still opens the TV's old screen, run the helper again and choose 3. To go back to the TV's own home screen at any time, choose 4 (Undo). When you're done, you can turn USB debugging off again.

Control the TV from your laptop (optional)

  1. Open Remote for Windows › ChillRemote.exe. Windows may say it's from an unknown publisher: choose More info › Run anyway.
  2. Right-click the round remote › Pair with a TV. Type the TV address and the pairing code shown on the TV: Chill TV Home Settings › Remote, or the phone icon on Chill TV Showcase. Every TV has its own code.

Remove Chill TV

If you used the PC helper, run it once more and choose 4 (Undo). Then remove the app in Settings › Apps › Chill TV › Uninstall.
